# Customer Trends Analysis 📊

A complete data analysis project focused on customer shopping behavior and purchasing trends using Python, Pandas, PostgreSQL, and Power BI.
The goal of this project is to explore customer data, identify meaningful business insights, and create interactive visualizations to support data-driven decision making.
The project was made during an exercise for a university exam. A complete report in pdf describe all the study. 

## 🚀 Project Overview

This project simulates a real-world data analytics workflow, starting from raw customer data and ending with business insights and dashboard visualization.

Main activities included:

* Data exploration and cleaning with Python
* Statistical analysis and trend discovery
* Database integration with PostgreSQL
* Interactive dashboard creation with Power BI
* Customer behavior analysis and reporting

⸻

## 🛠️ Technologies Used

* Python
* Pandas, sqlalchemy, psycopg2-binary
* PostgreSQL
* Power BI

⸻

## 📈 Analysis Workflow

1. Data Collection
The dataset contains customer shopping information including:

* Age
* Gender
* Purchase amount
* Product categories
* Payment methods
* Shopping frequency

2. Data Cleaning
Performed using Pandas:

* Missing value handling
* Duplicate removal
* Data type corrections
* Feature formatting

3. Exploratory Data Analysis
The analysis focused on:

* Customer demographics
* Spending distribution
* Most purchased categories
* Purchase frequency
* Correlation between variables

4. Database Integration
The cleaned dataset was imported into PostgreSQL to:

* Execute SQL queries
* Perform aggregations
* Simulate real business analytics scenarios

5. Dashboard Visualization
An interactive Power BI dashboard was created to visualize:

* Sales trends
* Customer segmentation
* Revenue analysis
* Product category performance
* Purchasing behavior patterns
